# Week 5 Documentation

## 1.1 Problem Statement
Create a Python program to automatically calculate a customer's cafe bill and print a receipt.

## 1.2 Inputs
- Customer name
- Coffee quantity
- Tea quantity
- Sandwich quantity

## 1.3 Outputs
- Receipt
- Total bill amount

## 1.4 Process Flow
1. Get customer name.
2. Get quantities of coffee, tea, and sandwich.
3. Calculate the total bill.
4. Print the receipt.
5. Display the total.

## 1.5 Constraints
- Quantities must be whole numbers.
- Prices are fixed:
  - Coffee = RM8.50
  - Tea = RM6.00
  - Sandwich = RM12.00

## 2. Problem Decomposition
- Input customer details.
- Calculate total price.
- Print the receipt.

## 3. Pseudocode

START

Input customer name

Input coffee quantity

Input tea quantity

Input sandwich quantity

Calculate total bill

Display receipt

Display total bill

END
